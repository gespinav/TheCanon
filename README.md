# The Canon

**Top 500 Film & Television Database · 1926–2026**

A curated, composite-scored canon of the 500 greatest films and television series,
with progress tracking, personal reviews in a newspaper aesthetic, and cloud sync.

Live: https://gespinav.github.io/TheCanon/
